Download

One program with all six applications, free. Pick your system.

Windows

64-bit Windows 10 and 11.

Installer (.msi) Without installing (.zip) Portable (.zip)

ARM (Snapdragon, Copilot+ PCs): .zip · portable

  • The installer adds ApexDesk to the Start menu and to “Open with”, and leaves your default applications alone.
  • The .zip needs no installing: unzip it and run ApexDesk.exe.
  • The portable version keeps its settings next to it, ready for a USB stick, and writes nothing to the registry or your profile.

Linux

Ubuntu 20.04, Debian 11, Fedora 32 or newer, and other 64-bit distributions, on x86-64 and ARM.

Debian, Ubuntu, Mint (.deb) Fedora, openSUSE (.rpm) Arch, Manjaro (.pkg.tar.zst) Flatpak (.flatpak) Portable (.tar.gz)

ARM (Raspberry Pi 4 and 5, ARM servers): .deb · .rpm · portable

  • The packages add it to the applications menu and to “Open with”, and leave your default applications alone.
  • The portable version runs from its folder, with its settings next to it.
  • Arch Linux and Manjaro: install it with sudo pacman -U and the package’s address, or build it yourself from packaging/linux/aur.
  • Flatpak: flatpak install --user and the downloaded file; the runtime comes from Flathub.

Android

Phones and tablets with Android 8.0 or newer, 64-bit and 32-bit ARM.

Android (.apk)
  • Open the file on the device and allow installing from that app when Android asks.
  • Everything but the database tab, with touch gestures and the system’s clipboard.

Mac

macOS 11 Big Sur or newer, Apple silicon and Intel.

macOS (.dmg)
  • Open the disk image and drag ApexDesk to Applications.
  • It isn’t notarized by Apple yet: the first time, right-click ApexDesk and choose Open.

Builds from the public code. The Windows installer and the macOS and ARM versions are built on GitHub from the public source code, without ApexDesk Empresa’s business features. Everything else is the same.

Windows SmartScreen. ApexDesk isn’t signed yet, so Windows may say “Windows protected your PC” the first time. Click More info, then Run anyway.

Requirements

System

  • Windows 10 or 11, or Linux, on 64-bit x86 or ARM processors.
  • macOS 11 or newer, on Apple silicon or Intel.
  • Android 8.0 or newer on 64-bit or 32-bit ARM, with OpenGL ES 3.0.
  • Disk space: the program takes 70 MB on Windows and 62 MB on Linux.
  • No graphics card needed.

Optional

  • Spelling: on Windows it uses LibreOffice’s dictionaries if it’s installed, or any Hunspell dictionary you put next to it; on Linux, the system’s.
  • Video and audio in presentations play through the system’s codecs.

Release

  • ApexDesk in the browser for apexdesk serve: unpack it next to the program (how)
  • Release notes and SHA-256 checksums
  • All versions
